# SAP DMLT Consolidation Study Assistant

AI-powered assistant for SAP consultants to analyze multi-system landscape data, run pre-defined calculations, assess data quality, and produce formatted Excel reports to support consolidation decisions.

## Business Challenge

SAP consultants conducting DMLT (Data Migration & Landscape Transformation) consolidation studies need to analyze raw SAP system statistics extracted as JSON files — covering table volumes, year-on-year growth, system profiles, org structures, and number ranges. Today this analysis is largely manual, time-consuming, and inconsistent across engagements. The consultant needs a tool that:

1. Reads one or more JSON extract files (master, growth, system, org, nriv sections)
2. Runs a pre-defined, deterministic set of calculations on the data (rules to be provided)
3. Applies AI reasoning to assess data quality and surface findings and recommendations
4. Produces a single, professionally formatted Excel report (matching a provided template) per run — containing statistics, charts, AI findings, and data quality flags
5. Stores run history so results can be compared across time or engagements

The number of SAP systems (sidclnt values) varies per engagement. The tool must support any number of systems and compare them against each other within the same run.

## Key Milestones

1. **JSON Ingested** — All section files (master, growth, system, org, nriv) successfully read and validated for the run
2. **Calculations Complete** — All pre-deterministic rules executed against the data, results stored
3. **AI Analysis Complete** — Data quality findings and recommendations generated by the AI layer
4. **Excel Report Generated** — Single formatted Excel file produced, matching the provided template, with all sheets, charts, and AI findings populated
5. **Run Stored** — Results and findings saved to run history for future comparison

## Recommendations

### AI Agent + CAP Backend for DMLT Consolidation Study

#### Executive Summary

Custom AI agent on BTP — reads JSON, runs rules, generates Excel report

#### Recommended Solution

Build a custom solution on SAP BTP consisting of:

- **AI Agent (Python, A2A protocol)**: Core reasoning layer — reads validated JSON data, applies pre-deterministic calculation rules, performs AI-driven data quality analysis, generates findings and recommendations
- **CAP Backend (Node.js)**: Handles JSON file ingestion and validation, stores run history in SAP HANA Cloud, triggers the AI agent, serves the Excel download link
- **Excel Generator (Python, openpyxl)**: Populates the user-provided Excel template with statistics, charts, and AI findings — one file per run
- **Joule Desktop**: End-user interface for SAP consultants — chat-based interaction to upload files, trigger analysis, and download the Excel report

#### Problem Statement

SAP consultants conducting DMLT studies manually process large, complex JSON extracts from SAP systems. This is slow, error-prone, and produces inconsistent outputs across engagements. A standardised, AI-powered tool will reduce analysis time, ensure consistency, and surface findings that manual review might miss.

#### Affected User Roles

- SAP DMLT Consultants (primary users — run the analysis, download the report)
- SAP IT Architects (consumers of the report — use findings for consolidation decisions)
- Engagement Managers (review AI recommendations and sign off on findings)

#### Important Factors

##### Calculation Logic is Pre-Deterministic
The AI agent does not invent calculation rules — all formulas and thresholds are explicitly provided by the user and hardcoded. The AI layer applies reasoning only for interpretation and recommendations on top of calculated results.

##### Template-Driven Excel Output
The Excel output must exactly match the user-provided template — sheets, layout, fonts, charts, and branding are all preserved. Only data cells are populated by the agent.

##### Run History Enables Trend Analysis
Storing each run in HANA Cloud allows consultants to compare results across time and engagements — a key differentiator over manual one-off analysis.

##### Variable System Count Per Engagement
The tool must handle any number of SAP systems (sidclnt values) in a single run — from 1 to many — and produce cross-system comparisons within the same Excel report.

#### Potential Risks

##### Joule Studio Subscription Not Yet Active
The Joule Desktop access depends on activating the Joule Studio subscription in BTP. Until this is done, the agent can be tested via SAP Build but not accessed by the broader team.

##### Calculation Rules Not Yet Provided
The deterministic calculation logic is critical to the agent's correctness. Development of the calculation engine will be blocked until the user provides the full rules.

##### Excel Template Not Yet Provided
The Excel generator cannot be built until the template is shared. Sheet names, column layouts, and chart structures must be known upfront.
